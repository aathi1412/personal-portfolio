# Personal Portfolio

A modern, responsive developer portfolio built with React and Vite to showcase my projects, technical skills, and experience as a Java Full Stack Developer.

## Preview

The portfolio includes:

* Home / Hero section
* About Me
* Skills
* Featured Projects
* Contact
* Dark & Light theme
* Responsive design

## Built With

* React 19
* Vite
* Tailwind CSS 3
* React Router DOM
* React Icons
* Lucide React

## Getting Started

Clone the repository:

```bash
git clone https://github.com/aathi1412/portfolio.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
